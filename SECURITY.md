# Security reports

Sigy is an early development project with no maintained release series. Reports are assessed against the current `main` branch. Platform, native-worker isolation, and recovery limitations are recorded in [implementation progress](docs/development/progress.md).

Use [GitHub private vulnerability reporting](https://github.com/blisspixel/sigy/security/advisories/new) when the private reporting form is available. Do not post exploit details, credentials, recordings, or private source addresses in public issues. If the form is unavailable, open an issue requesting a private contact route without technical details.

Include the affected commit, operating system, relevant configuration, impact, and a minimal reproduction using synthetic or redistributable inputs. Remove secrets and personal data. No response deadline or bounty is promised.

For ordinary bugs and usage questions, follow [CONTRIBUTING.md](CONTRIBUTING.md).
