## 2026-10-20 committed claim binding

The [2026-10-20 amendment](../decisions/0092-atomic-worker-responses.md) binds recognition and translation finish to the attempt and lease owner stored by the committed claim. ## Open gates and known limitations

- **Network isolation:** native recognizers are not network-sandboxed by the operating system. Static import checks only. Gate for recognition on user recordings before release.
- **Process containment:** Windows uses bounded Job Objects. The experimental Linux delegated systemd-user adapter now passes actual process/thread/task, memory/CPU, cancellation and owner-death contracts; missing delegation still fails closed. See [Decision0090](../decisions/0090-desktop-discovery-and-native-listening.md). Same-user cgroup mutation is outside this resource boundary, and recognizer/translator runtime qualification remains separate. macOS fails closed. The Windows suspended-spawn assignment window remains. After a restart, only Windows requeues native jobs; Linux and macOS interrupt them.
- **Recognition scope:** one job publishes one transcript. Each process hears at most 30 seconds, at most 1,024 windows, with the 64 MiB byte cap unchanged. A phrase at a window edge while audio remains waits, and the next window starts at that phrase. A phrase with no earlier break is stored through the window end. Model hashing takes seconds per run. Each window still runs with `language=auto`.
- **Quality:** no language is qualified. The 32-clip calibration has limited reference diversity, and the 126-control judge profile failed. A calibrated independent evaluator, broader published references and the unopened holdout remain necessary.

- **Platforms:** Ubuntu CI passes delegated native and loopback media/restart contracts; macOS CI passes build/lint, private IPC and platform contracts.
