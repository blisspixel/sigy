# Offline country and territory reference

Reviewed: 2026-10-03. CLDR 48.2.0 is stable; CLDR 49 is beta at this review. Original territory JSON bytes are retained from commit `bb334e8d6250c9363e957e131bf7e6d08ec72f91` of the [official CLDR JSON repository](https://github.com/unicode-org/cldr-json/tree/bb334e8d6250c9363e957e131bf7e6d08ec72f91). [Release status](https://cldr.unicode.org/) and [release tag](https://github.com/unicode-org/cldr-json/releases/tag/48.2.0) were checked before import.

`provenance.json` records exact input URLs and SHA-256 hashes. The original [Unicode 17.0 full case-folding table](https://www.unicode.org/Public/17.0.0/ucd/CaseFolding.txt) is also retained unchanged. `LICENSE` preserves the upstream CLDR notice; `UCD-LICENSE` preserves the Unicode license obtained from [the official license](https://www.unicode.org/license.txt). These notices must travel with copies and are embedded unchanged in the executable, accessible through `radio countries --licenses` in text or JSON. Runtime parsing and matching are Rust code in `discovery::countries`; there is no data generator, build-time fetch or runtime fetch.

The selectable reference includes every base two-uppercase-ASCII-letter territory key in the English data, with the same labels required in all eight bundled locales, except `EU`, `EZ`, `QO`, `UN`, `XA`, `XB`, `ZZ` and the deprecated `SU`. Numeric macroregions and all alias-key suffixes are excluded as separate entries. Exceptional territories `AC`, `CP`, `CQ`, `DG`, `EA`, `IC`, `TA` and `XK` remain selectable. Inclusion and upstream wording assert neither sovereignty nor ISO assignment, Radio Browser availability or supported reception. Deprecated and other absent provider codes can still be used explicitly through the existing two-letter filter contract; they have an unlisted label.

Display locales are `en`, `fr`, `es`, `ar`, `hi`, `zh`, `pt`, `sw`. A different requested locale, including `fr-CA`, explicitly falls back to `en`; no regional inheritance or automatic locale guessing is claimed. Search considers base labels and alternate labels from all eight locales. These labels concern geography, never observed speech. English is the terminal picker's initial display locale; users can cycle its bundled locales.

Matching uses NFC, Unicode 17 default full non-Turkic folding, then NFC. Accents and scripts remain distinct. There is no compatibility, transliteration, accent-removal or confusable assistance in this increment. ASCII two-letter input takes precedence as a literal provider code. Other input uses a normalized substring across every alias; all candidate codes determine ambiguity before a page is cut. Each returned entry identifies reference-list, explicit-code or name-substring matching; a name match includes its original alias and source locale. Code ordering is stable and independent of locale collation. Queries are limited to 128 UTF-8 bytes, canonical query/alias keys to 512 bytes, locales to 32 bytes and returned pages to 16 entries. Each retained locale document is bounded to 32 KiB before parsing, the Unicode folding table to 128 KiB, and labels to 256 bytes. The immutable reference has at most 300 entries with at most 64 distinct alias keys per entry and 2,048 folding mappings of at most 12 bytes each. Input controls and direction overrides are refused by the resolver and removed by the terminal's existing presentation sanitizer.

[`unicode-normalization` 0.1.25](https://docs.rs/unicode-normalization/0.1.25/unicode_normalization/) provides Unicode 17 normalization under MIT/Apache-2.0. Its only activated transitive dependency is the already locked `tinyvec` 1.13.3, licensed under Zlib/Apache-2.0/MIT. The import adds one package and no native library, macro dependency or model. The first-party tests check the manifest and every retained asset hash, the normalization Unicode version, all 257 included codes/locales, canonical equivalence, malicious inputs, explicit raw-code fallback, ambiguity and cursor scope. Updates must change the pinned inputs, manifest hash and reference contract, inspect the complete dependency graph, and rerun these checks. Do not silently retain an old cursor contract after changing matching or inclusion.
