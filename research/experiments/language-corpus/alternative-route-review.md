# Alternative corpus route review

Reviewed: 2026-09-22. Metadata and HEAD requests only. No audio, model, or archive was downloaded. This is a candidate redesign, not a change to the frozen 112-clip plan.

## Original FLEURS test-only route

Source repository revision: `google/fleurs@70bb2e84b976b7e960aa89f1c648e09c59f894dd`. License: CC BY 4.0 in the pinned dataset card, with attribution obligations. The eight `data/{config}/audio/test.tar.gz` objects already listed with LFS hashes in `archive-acquisition.json` sum to exactly 3,193,520,534 bytes. They contain the ten previously frozen holdouts per survey language. The sixteen train and test objects together sum to 16,113,568,959 bytes and exceed the 10 GiB cumulative new-download cap. These are full-object routes, not per-clip access. The converted Parquet row-group route is also over cap; see `parquet-acquisition-review.md`.

One limited redesign is eight original test archives plus the `hi_in` and `sw_ke` original train archives. Their three components total 3,193,520,534 + 1,256,867,167 + 2,421,455,236 = **6,871,842,937 bytes** before models, metadata, retries or any other corpus. Their archived LFS SHA-256 values are in `archive-acquisition.json`. This only preserves FLEURS train/test speaker separation for Hindi and Swahili. It does not preserve the frozen 32-clip calibration set, which has four train clips for each of eight languages. A new manifest and pre-acquisition storage/asset budget are required before any download.

## Tatoeba per-audio candidate for six languages

Primary sources: [download and license instructions](https://tatoeba.org/en/downloads), [API schema](https://api.tatoeba.org/openapi), [text and audio reuse guidance](https://en.www.en.wiki.tatoeba.org/articles/show/using-the-tatoeba-corpus). Tatoeba text uses CC BY 2.0 FR by default, while each audio has its contributor-selected license, which may be different or absent. Do not infer audio permission from text. The current API is mutable; a future fixed subset must retain exact sentence/translation/audio IDs, author, license, attribution URL, source response hashes, and audio SHA-256. No immutable dataset revision was established from these endpoints.

Read-only query form: `https://api.tatoeba.org/v1/sentences?lang={code}&has_audio=yes&sort=created&limit=1`. The `paging.total` values returned on 2026-09-22 were `fra=9818`, `spa=119357`, `por=20957`, `ara=483`, `cmn=5826`, `eng=849551`, `swh=0`, `hin=0`, `nav=0`, `tlh=0`. Querying `swa` returned HTTP 400, not a second positive Swahili code. With `trans%3Alang=eng`, the six positive totals were `fra=9776`, `spa=106818`, `por=20369`, `ara=476`, `cmn=5766`, `eng=304655`. Counts are live search-result counts, not a verified subset. English-to-English translations are not needed for English calibration.

`GET https://api.tatoeba.org/v1/sentences/11596318?include=audios` returned French sentence 11596318, audio ID 1092402, contributor `Adrien_FR`, and audio license CC BY-NC 4.0. `HEAD https://tatoeba.org/audio/download/1092402` returned HTTP 200, `audio/mpeg`, `Content-Length: 31739`. This proves one direct file route without downloading its body. The API's returned `download_url` and OpenAPI path produced HTTP 404 in the local HEAD probe, so use the documented Tatoeba web download endpoint and verify every selected file before transfer. The example is not approved for a benchmark subset or hosted inference; its license may be unsuitable. The metadata export `https://downloads.tatoeba.org/exports/sentences_with_audio.tar.bz2` returned HTTP 200 to HEAD, declared 6,376,599 bytes, Last-Modified `Sat, 19 Sep 2026 06:27:43 GMT`, and ETag `"6aae2b5f-614c97"`. It was not downloaded. These headers do not create an immutable release.

Tatoeba can potentially provide licensed independent calibration audio and references for French, Spanish, Portuguese, Arabic, Mandarin and English, if exact eligible records are selected. It has no audio search results for Swahili and Hindi in this API check. Cross-corpus speaker separation from FLEURS cannot be proved because the reviewed FLEURS rows lack speaker IDs, though Tatoeba supplies contributor identities for its own recordings. Parallel English links, recording quality, duration, audio hashes and exact per-language contributor diversity have not been verified. Exact or near-duplicate texts must be excluded against all FLEURS calibration and holdout references before freezing any replacement. This redesign could support a disclosed smoke comparison, not the originally planned qualification or a claim of speaker-independent accuracy.

No acquisition is recommended from this receipt alone. Preserve the frozen manifest until a separate replacement selection is accepted and bounded.
